# TheoGrace XMAS v8 — Mystery Gift Wheel

Adds a 5-second automatic mystery wheel before the real personalization clues.

- No product photos or jewelry silhouettes in the wheel.
- Wheel vocabulary adapts to Necklace, Bracelet, and Photo/Locket families.
- It slows toward a reveal, then blurs before stopping.
- “Nice try… We’re keeping that part a secret.”
- The next scene reveals only real personalization clues.
- Total experience remains 45 seconds.
- Existing TheoGrace logo, Nicky photo, packaging, Supabase route, ETA and XMAS30 are preserved.
- Existing demo URLs are preserved.
