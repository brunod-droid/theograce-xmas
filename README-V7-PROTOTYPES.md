# v7 — product-safe prototypes

This version keeps the 45-second experience and makes the jewelry reveal product-safe:

- Never renders a necklace, bracelet, bar, bead, heart, pendant or other jewelry silhouette.
- Uses the real TheoGrace packaging reference instead.
- Product family can drive copy later, but does not invent the product design.
- Personalization values are revealed typographically, not as fake jewelry.
- Recipient name is optional; the experience reads naturally without it.
- Keeps the existing TheoGrace logo and Nicky photo assets.
- Nicky's note is styled as handwriting.
- Final screen includes ETA `Monday 28` and `$30 OFF` coupon `XMAS30`.
