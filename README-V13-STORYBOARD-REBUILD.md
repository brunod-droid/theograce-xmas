# TheoGrace XMAS v13 — Storyboard Rebuild

This version is a visual rebuild rather than another wheel patch.

- Rebuilt around the warm Christmas storyboard direction.
- Removed the empty framed jewelry box from the clue scene.

- Jewelry remains fully visible while the wheel spins; the whole wheel disappears before selection.
- More warm gold bokeh, snow, ribbon, gift packaging and Christmas-card composition.
- Fewer interface-like surfaces and dark empty screens.
- Nicky scene is composed like a physical holiday card.
- Final ETA/coupon scene is styled as a Christmas card, not a dashboard.
- Existing Supabase data contract and demo routes are unchanged.
