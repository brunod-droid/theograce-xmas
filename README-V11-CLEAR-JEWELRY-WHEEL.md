# TheoGrace XMAS v11 — Clear Jewelry Wheel

This version deliberately removes the concealment effect from the wheel.

## Intended moment
1. The recipient sees multiple real jewelry product images clearly.
2. Images are large, crisp, bright and fully opaque while the wheel spins.
3. The wheel slows down as if it is about to select a product.
4. It NEVER lands on one product.
5. The entire wheel disappears in a short bright flash.
6. Copy: “Nice try… your gift stays a secret.”
7. The experience continues to the real order personalization clues.

The wheel is allowed to show possible jewelry. It is not allowed to identify one
of those products as the recipient's actual gift.

No Supabase schema changes are required.
